Hello, and thank you for purchasing Luna Pterodactyl theme by Buzz Development

Quick install

1. Upload the Luna zip file to your Pterodactyl panel root, usually /var/www/pterodactyl
2. From that same folder, extract the bootstrap installer:
unzip -oj luna-pterodactyl-theme-1-9-6.zip Product/install.sh
3. Run the installer:
bash install.sh --version 1-9-6

You can also run:
bash install.sh luna-pterodactyl-theme-1-10-8.zip --zip

If there is only one Luna zip in the folder, this also works:
bash install.sh

The installer will preserve supported addon files, replace the theme files, run migrations, rebuild assets, and bring the panel back up.
